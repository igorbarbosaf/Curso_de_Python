# Curso de Python

Este repositório contém os materiais e exercícios do curso de Python.

## 📁 Estrutura do Projeto

### 📚 Aulas Principais (Raiz do Projeto)
- `Primeiros_Passos.ipynb` - Introdução ao Python
- `Função_if-else.ipynb` - Estruturas condicionais
- `While_Enquanto.ipynb` - Loops while
- `For_Para.ipynb` - Loops for
- `Funções.ipynb` - Funções em Python
- `Listas.ipynb` - Trabalhando com listas
- `Tuplas.ipynb` - Trabalhando com tuplas

### 🎯 Mini Projetos
Localizados em `mini_projetos/`:
- `calculadora.ipynb` - Calculadora simples
- `caixa_eletronico.ipynb` - Simulador de caixa eletrônico
- `analisador_de_texto.ipynb` - Analisador de texto

### 💻 Práticas
Localizados em `praticas/`:
- `prat1_novo.ipynb` - Prática 1
- `prat2_intro.ipynb` - Prática 2 - Introdução
- `prat3.ipynb` - Prática 3

## 📝 Notas
- Todos os arquivos estão organizados por categoria
- Não há arquivos duplicados ou temporários
- A estrutura está limpa e bem organizada

## 🚀 Como Usar
1. Abra os notebooks Jupyter na ordem sugerida (começando por `Primeiros_Passos.ipynb`)
2. Execute as células para aprender os conceitos
3. Pratique com os exercícios nas pastas `praticas/` e `mini_projetos/`
